# MUSIC

What's playing on this computer (Spotify, Music, any player on Linux) with play / pause / skip / volume: a HOME widget and the `music` command

**Ships with ICEBREAKER** (since 0.4.0): remove it in MODULES, put it back from the STORE —
the deck's own copy comes back, nothing is downloaded.

This folder is its source, to read and to learn from: `main.ts` uses the same `ib` API as
any module (docs/PLUGINS.md in the ICEBREAKER repository).
